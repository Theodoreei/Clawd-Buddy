Connections

Link Clawd to your apps so he can read and act in them.

GH
GitHubNot connected
if you've run gh auth login

Or make a token at github.com › Settings › Fine-grained tokens: pick the repositories, and give Contents, Issues, Pull requests and Metadata access (read-only is fine if you only want Clawd to look).

Uses GitHub's official MCP server: repos, files, issues, pull requests, Actions, code search.

◢
LinearNot connected

In Linear, open Settings › Security & access and create a personal API key (choose Read only if you just want Clawd to look).

Uses Linear's official MCP server: issues, projects, cycles, comments, docs.

With the Claude API brain, GitHub, Linear and other app servers are called by Claude directly, so Clawd tells you what he's about to change and waits for your OK in the chat rather than in an Allow button. With the Claude account brain, each change comes to his Allow / Deny bubble.

#
SlackNot connected
  1. Create a Slack app at api.slack.com/apps (From scratch).
  2. Under OAuth & Permissions, add scopes: channels:read, channels:history, groups:read, groups:history, chat:write, users:read (and search:read as a user scope to search).
  3. Install it to your workspace and paste the User token (xoxp-…, posts as you) or Bot token (xoxb-…, posts as the app).
  4. For message summaries, use the User token and add search:read under User Token Scopes.

Clawd can list channels, read and search messages, and send messages. He always asks before sending.

⇄
Other apps (MCP servers)Notion, Asana, Atlassian, Sentry and more publish remote MCP servers.

Paste the app's remote MCP URL (https) and, if it needs one, an access token. Claude calls these servers directly, so their actions run without Clawd asking first: only connect apps you trust.

Claude chats

Pick up a chat from the Claude app's Code tab or from Claude Code, and keep going with Clawd. He continues it in a copy, so the original chat is never changed.

Conversations from the Claude app's Chat tab are stored on Anthropic's servers, and apps can't read them, so only Code-tab and Claude Code chats appear here. Continuing a chat switches Clawd's brain to your Claude account.

Claude Code

Let Clawd hand coding jobs to Claude Code: building apps and scripts, editing projects, fixing bugs, running tests.

Projects folder

Where new projects go when you don't name a folder. You can also say “in ~/Code/my-app”.

What Claude Code may do on its own

Claude Code uses its own sign-in (your Claude subscription or its API key), not Clawd's key.
